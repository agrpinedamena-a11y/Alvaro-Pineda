## Herramientas

El repositorio se trabaja con [Claude Code](https://claude.com/claude-code) y el plugin
[codex-plugin-cc](https://github.com/openai/codex-plugin-cc) para revisiones de código con Codex.

Requisitos para usar el plugin:

- Node.js 18.18 o superior
- Codex CLI (`npm install -g @openai/codex`) con sesión iniciada (`codex login`)
